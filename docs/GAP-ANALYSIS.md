# Clover vs Claude Code 严格差距分析

> 2026-09-01 · 基准版本 v0.1.2（本表随 v0.1.3 更新）
> 定位说明：Claude Code 是通用编码 Agent 标杆；Clover 是“黑客松专用的编码 Agent”，在保留黑客松能力的前提下尽量对齐 Claude Code 的手感。

| 能力 | Claude Code | Clover v0.1.2 | 差距 | 状态 |
| --- | --- | --- | --- | --- |
| 流式输出（逐 token 显示） | ✅ | ❌ 整段等待 | 大 | ✅ v0.1.3 已实现（4 家 Provider 全支持） |
| 思考/等待指示 | ✅ spinner | ❌ 无 | 中 | ✅ v0.1.3 思考中提示 |
| 工具调用卡片（参数/结果/✓） | ✅ 展开式卡片 | ⚠️ 一行 dim 日志 | 大 | ✅ v0.1.3 基础卡片 |
| Esc 中断生成 | ✅ | ❌ | 中 | P1 |
| 多行输入 / 软换行 | ✅ | ❌ 单行 | 小 | P2 |
| 命令历史（↑） | ✅ | ✅ readline 自带 | 无 | - |

## 路线图

- **v0.1.3（本次）**：流式输出、思考指示、工具卡片、/cost、/clear、开场状态行、宠物开场修正、差距文档
- **v0.2**：TUI 重构（ink）、底部状态栏、Esc 中断、上下文自动压缩、CLOVER.md 项目记忆
- **v0.3**：Plan 模式、会话选择器、对话中切换模型、Markdown 渲染

## 结论

Clover 在“编码 Agent 基础能力”（工具、权限、多模型、会话、成本）上已基本对齐 Claude Code；最大差距集中在**交互层**：流式与 TUI。v0.1.3 先补齐流式与对话内反馈，v0.2 用 TUI 重构界面。
