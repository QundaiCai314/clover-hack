# Clover（三叶草）— 黑客松比赛搭档 CLI · PRD

> 版本：v0.1（需求确认稿）
> 日期：2026-09-01
> 状态：已完成 24 轮需求确认，进入开发

## 1. 产品概述

Clover 是一个**专为黑客松比赛设计的命令行 AI Agent**。它以 Claude Code 风格的终端交互为体验基准，具备完整通用 Agent 能力（文件读写、命令执行、联网搜索、多模态、多模型），同时内置黑客松专属工作流：赛题解析、点子评估、MVP 规划、时间管理、提交检查、Pitch 辅助、赛后复盘。

一句话：**参赛者全程的比赛搭档，从读到赛题到提交作品的每一步都有人帮。**

## 2. 目标用户

- 核心用户：本人（个人参赛者，Windows 为主）
- 扩展用户：其他黑客松参赛者（npm 全局安装，跨平台）
- 单人使用，无团队协作需求（v1 不做多人/权限）

## 3. 场景与形态

- 比赛形式：线上黑客松，时长 48 小时 ~ 一周
- 交互形态：终端对话式 CLI（一问一答 + 工具调用实时展示 + 文件改动 diff 展示 + 多行输入 + 快捷键 + 会话恢复），风格参考 Claude Code
- 产品形态：独立 CLI 命令 `clover`，`npm install -g` 分发
- 开源：公开 GitHub 仓库，MIT 协议，接受社区贡献

## 5. 黑客松专属功能

| 功能 | 说明 | 优先级 |
| --- | --- | --- |

## 6. 命令设计（v1）

```text
clover init                     # 在当前目录初始化比赛项目
clover new <name>               # 创建新比赛档案（独立目录 + 全局档案注册）
clover start                    # 进入 Agent 对话模式（核心）
clover analyze <赛题文件/URL>    # 赛题解析
clover ideate                   # 点子生成（基于当前赛题档案）
clover evaluate <idea>          # 点子评估（联网市场分析）
clover plan                     # MVP 规划
clover template <readme|pitch|submission|timeline>
clover check                    # 提交检查清单
clover review                   # 赛后复盘（手动触发）
clover status                   # 当前比赛状态：倒计时/进度/预算
clover config                   # 配置向导（模型、语言、预算、竞速模式）
clover models                   # 模型管理/切换
clover archive list             # 历史比赛档案
```

## 7. 非功能需求

### 7.1 模型接入

- 统一 Provider 抽象层，支持：OpenAI、Anthropic、Gemini、Ollama、自定义 OpenAI 兼容接口
- 配置方式：`clover config` 交互式向导生成 + 手动编辑配置文件，双通道
- 模型可切换，比赛档案可绑定默认模型

### 7.2 语言

- 界面与文档语言可配置（`clover config`），默认中文

### 7.3 成本控制

- 每次会话统计 token 消耗与估算费用（按各家公开定价表）
- 支持设置预算上限，接近/超出时提醒（可配置是否强制）

### 7.4 安全与权限

- 命令执行默认需用户确认（类似 Claude Code 手动批准）
- 提供"竞速模式"（speed mode）：可自动执行用户已批准类型的命令，全程留日志、可中断
- 定时自动 git commit 备份（默认间隔 30 分钟，可配置），防丢失

### 7.5 Git 集成

- 自动生成规范的 commit message
- 赛前自动打 tag/备份
- 定时自动 commit（防手滑丢代码）

### 7.6 数据存储

- 比赛项目：每个比赛一个工作目录，`.clover/` 内存会话、档案、成本数据
- 全局数据：`~/.clover/` 存配置、全局档案索引、历史比赛记录、复盘报告
- 数据全本地，不上传（API Key 仅存本机）

### 7.7 平台与分发

- 主开发/使用平台：Windows；发布目标：npm 跨平台（Win/macOS/Linux）
- 分发：`npm install -g clover`（npm 包名若被占用则用 `clover-hack`）
- 命令行名：`clover`（三叶草，幸运属性）

## 8. 技术方案

- 语言/运行时：TypeScript + Node.js（>= 20）
- 交互：基于 Ink/自研终端 UI 组件，风格对齐 Claude Code
- Agent 核心：基于开源项目（Codex CLI / Claude Code 替代品）改造或借鉴其工具循环设计，重点自研黑客松工作流层
- CLI 框架：commander；配置校验：zod；模板：内置 Markdown 模板 + 渲染
- 搜索：内置搜索工具（Bing/DuckDuckGo/SerpAPI 可配置）
- 多模态：图片/PDF 解析（PDF 本地解析 + 模型视觉能力）

## 10. 里程碑

| --- | --- | --- |
